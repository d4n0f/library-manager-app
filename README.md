# Library Manager

## Overview

This is an ASP.NET & Blazor-based web application for managing books, readers, and rentals in a library.

## Features

- Full CRUD functionality
- Custom validations
- Local database integration
- Simple user interface

## Notes

- Some validations require refactoring.
- A few unused services remain and should be cleaned up or removed in a future update.
